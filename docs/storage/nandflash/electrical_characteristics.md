# Electrical Characteristics

This section outlines the physical pin configurations, interface definitions, and signal behaviors for SPI/QSPI bus communications with the serial NAND flash device.

## Interface Definitions

The pin definitions and signal directions defined below are viewed from the NAND Flash device's perspective. The bus includes a clock line, chip select, and serial data/IO lines, with optional hardware protection and strobe signals.

| Name | Type* | Description |
| :--- | :--- | :--- |
| **CS#** | I | Chip Select input, active low |
| **SI / SIO0** | I/O | Serial Data Input / SIO0 |
| **SO / SIO1** | I/O | Serial Data Output / SIO1 |
| **WP# / SIO2** | I/O | Write Protect / SIO2 |
| **HOLD# / SIO3** | I/O | Hold Input / SIO3 |
| **SCLK / CLK** | I | Serial Clock input |
| **VCC** | S | Power Supply |
| **VSS / GND** | S | Ground |
| **NC** | - | Not Connect |
| **DQS** | O | Data Strobe Signal Output (only for BGA24) |

*NOTE: I: input; O: output; I/O: bidirectional; S: power supply; NC: not connected.*

## Signal Behaviors

* **Chip Select (CS#)**: Must be driven high if the chip is not selected. The CS# line must never be left floating at any time after power is on. After power-up, CS# must transition from high to low before a new instruction will be accepted.
* **Serial Clock (SCLK / CLK)**: Dictates the timing relationship between clock edges and data transfers. SPI NAND devices typically support operational Mode 0 (CPOL=0, CPHA=0) and Mode 3 (CPOL=1, CPHA=1).
* **Data Lines (SIO0–SIO3)**: Bidirectional or unidirectional channels depending on the current bus configuration (Standard, Dual, or Quad SPI). During Quad SPI operations, all four pins (SIO0 to SIO3) are used concurrently to multiplex data input/output and significantly increase throughput.
* **Write Protect (WP#) and Hold (HOLD#)**: If WP# and HOLD# are unused by the application design, they must be driven high by the host or tied to an external pull-up resistor on the PCB to prevent floating states.
* **Data Strobe (DQS)**: Generated by the flash device in specific high-performance packages (such as BGA24) to synchronize data output with the controller. If the DQS function is not used, the pin must be left floating.
