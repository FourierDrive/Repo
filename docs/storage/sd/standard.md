# Standard

The SD standard version has been released since 2000, supporting dual-voltage operation modes as well as 1-bit and 4-bit bus widths right from its initial version. Prior to version 4.00, supported SD specifications utilized a 4-bit parallel bus width, achieving a theoretical transmission speed of 104 MB/s at a clock frequency of 208 MHz.

## Version 4.00

Released in 2011, introduced a new speed mode using low-voltage serial differential bus technology to further elevate theoretical transmission speeds.

## Version 5.00

Released in 2016, unified the card capacity standards and speed classification specifications.

## Version 6.00

Released in 2017, introduced a new speed mode to further enhance theoretical transmission speeds.

## Version 7.00

Released in 2018, improved both speed and capacity, rolling out larger capacity specifications and adding support for PCIe bus transmission.
